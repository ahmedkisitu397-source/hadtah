How to install

Windows apps work on Windows 10 and 11, Android apps on most Android phones. Web apps (TTu, Eilpah) just open in your browser.

Windows: if you see “Windows protected your PC” (SmartScreen), click More info, then Run anyway.

Android: when you open the APK, your phone may ask you to allow installs from this source. Tap Settings, turn it on, go back and tap Install.

Both warnings are normal for new apps that are not yet signed by a store.

  1. 1

    Download

    Press Download on the app you want. The setup file goes to your Downloads folder. You can also copy it to a flash drive to install on PCs with no internet.

  2. 2

    Open the setup file

    Double-click the file. If Windows shows “Windows protected your PC”, click More info, then Run anyway. This appears for new apps that are not yet signed; it is normal.

  3. 3

    Install

    Click Next, tick Create a desktop shortcut, then Install and Finish.

  4. 4

    Use it

    Double-click the new desktop icon. To remove an app later, go to Settings › Apps › Installed apps and choose Uninstall.
